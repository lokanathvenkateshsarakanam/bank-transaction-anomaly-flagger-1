DMGT Unit 2: Transaction Relations & Equivalence Classes Quotient Set A / R

Evaluates binary relations $R \subseteq A \times A$ over device fingerprints, IP addresses, and national IDs. Proves Reflexive, Symmetric, and Transitive properties to partition accounts into equivalence classes $[x]$.

Relation $R_{\text{device}}$ Properties:
  • Reflexive: $\forall x \in A, (x, x) \in R$ (Every account shares its device with itself).
  • Symmetric: $(x, y) \in R \implies (y, x) \in R$ (Device sharing is bidirectional).
  • Transitive: $(x, y) \in R \land (y, z) \in R \implies (x, z) \in R$ (Equivalence links propagate).
  • Equivalence Relation: TRUE (Valid Partition)

Curriculum & Academic Syllabus Integration

1. DMGT (Discrete Mathematics & Graph Theory)

Unit 1: Propositional logic AST with connectives ($\neg, \land, \lor, \implies, \iff$), Modus Ponens inference, and $2^n$-row truth tables.
Unit 2: Binary relations $R \subseteq A \times A$, equivalence relation properties, quotient set $A/R$, and multi-hop relational composition $R \circ S$.

2. AI (Artificial Intelligence)

Unit 1: Rational Agent architecture based on PEAS framework. Evaluates posterior fraud belief $P(\text{Fraud})$ and selects action maximizing Expected Utility: $a^* = \arg\max_{a} EU(a)$.

3. ADSA (Advanced Data Structures & Algorithms)

Unit 2: Transaction network represented as a Directed Graph with adjacency lists. Employs 3-color DFS cycle detection for circular money laundering ($A \to B \to C \to A$) and fan-in velocity analysis for smurfing rings.

4. Bottle & Snowflake Frameworks

Bottle: WSGI micro-web server providing RESTful JSON APIs and this dashboard.
Snowflake: 64-bit distributed ID generation (Twitter Snowflake specification) and cloud data warehouse dimensional schema (`FACT_TRANSACTIONS`, `DIM_ACCOUNTS`, `DIM_ANOMALY_AUDIT`).
